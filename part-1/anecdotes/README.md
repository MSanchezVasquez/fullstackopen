# Anecdotes

Aplicación de React para mostrar y votar por anécdotas.

## Descripción

Este ejercicio muestra cómo usar estado en React, manejar eventos y renderizar listas. La aplicación permite:

- Mostrar una anécdota aleatoria.
- Votar por anécdotas.
- Mostrar el conteo de votos.

## Comandos

```bash
npm install
npm run dev
```

## Uso

1. Ejecuta `npm install` para instalar dependencias.
2. Ejecuta `npm run dev` para iniciar la aplicación.
3. Abre el navegador en la dirección que indique el servidor Vite.
