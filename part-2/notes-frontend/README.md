# Notes Frontend

Frontend de React para una aplicación de notas que usa `json-server` como backend local.

## Descripción

Esta aplicación muestra cómo comunicar un frontend React con un servidor REST local. Permite:

- Listar notas desde `db.json`.
- Crear nuevas notas.
- Filtrar notas por texto.

## Comandos

```bash
npm install
npm run server
npm run dev
```

## Uso

1. Ejecuta `npm install`.
2. En una terminal, inicia el servidor local con `npm run server`.
3. En otra terminal, ejecuta `npm run dev`.
4. Abre la aplicación en el navegador y añade o filtra notas.
