# Full Stack Open - Resumen de ejercicios

Este repositorio contiene los ejercicios del bootcamp Full Stack Open organizados por partes.

## Estructura del repositorio

- `part-0/` - Configuración inicial y recursos básicos.
- `part-1/` - Fundamentos de React y primeros componentes.
  - `anecdotes/` - Aplicación de anécdotas con estado y efectos.
  - `comments-unicafe/` - Ejemplos de manejo de eventos y estado en React.
  - `courseinfo/` - Despliegue de información de cursos con componentes.
- `part-2/` - React avanzado, llamadas a APIs y gestión de formularios.
  - `country-data/` - Búsqueda de países y detalles usando APIs externas.
  - `notes-frontend/` - Aplicación de notas con frontend React.
  - `phone-book/` - Agenda telefónica con creación y filtrado de contactos.
- `part-3/` - Backend con Node, Express y MongoDB.
  - `notes-backend/` - API de notas con pruebas automáticas.
  - `phone-book/` - API de agenda telefónica con MongoDB.
- `part-4/` - Backend y testing avanzados.
  - `blog-list-backend/` - API de blogs con autenticación y pruebas.

## Cómo usarlo

Cada subproyecto tiene su propio `README.md` con instrucciones específicas.

Pasos generales:

1. Abrir un terminal en la carpeta del proyecto deseado:
   ```bash
   cd part-<n>/<proyecto>
   ```
2. Instalar dependencias:
   ```bash
   npm install
   ```
   o si prefieres usar pnpm:
   ```bash
   pnpm install
   ```
3. Iniciar la aplicación:
   ```bash
   npm run dev
   ```
   o el comando que indique el `README` local de cada proyecto.

## Notas

- Cada parte del bootcamp está documentada a nivel local en el README de su carpeta.
- En `part-3/notes-backend/` y `part-3/phone-book/` hay ejemplos de APIs que usan MongoDB.
- En `part-4/blog-list-backend/` está el backend para la parte de blogs.

## Recomendación

Para revisar un ejercicio específico, entra en su carpeta y consulta su propio `README.md`.
